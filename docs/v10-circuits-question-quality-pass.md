# v10 circuits question-quality pass

This pass focuses on making **7J Current electricity** questions tougher and more exam-like without adding another mode or changing the static GitHub Pages architecture.

## What changed

- Rewrote **87 existing 7J question cards**.
- Kept the deck size stable at **422 cards**.
- Kept the v9 circuits diagram set and symbol label lab intact.
- Removed remaining cross-topic joke/easy distractors from 7J multiple choice and visual questions.
- Replaced simple recall stems with:
  - scenario-based questions
  - prediction questions
  - best-explanation questions
  - circuit-rule questions
  - common misconception checks
- Improved feedback cues so wrong answers are more diagnostic.

## Question quality targets

The rewritten questions now focus more heavily on:

- current as flow of charge
- voltage as energy transfer / push
- resistance reducing current
- ammeter in series
- voltmeter in parallel
- series current rule
- parallel branch rule
- series vs parallel consequences
- AND / OR switch logic
- fuse and plug safety
- wire resistance factors
- circuit diagram mistake diagnosis

## Difficulty distribution for 7J answerable questions

The 7J answerable question set now emphasises middle-to-high difficulty:

- Difficulty 3: foundation but not joke-easy
- Difficulty 4: main target level for exam practice
- Difficulty 5: multi-step visual reasoning / misconception diagnosis
