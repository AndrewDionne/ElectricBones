# V7 Pack Alignment Drill Notes

This patch was applied to the uploaded Electric Bones static app.

## Purpose

Tighten the app against the Year 7 revision pack without expanding the deck. The focus is wording, metadata, and a study mode organised like the pack.

## Changes

- Preserved existing card IDs by adding an `Id` column to `data/flashcards.csv`.
- Added `Pack section` and `Source focus` fields to the CSV and generated JS.
- Added a new **Pack drill** mode to the home screen and study controls.
- Added a **Revision pack map** dashboard with section-level mastered counts.
- Reworded 187 card fronts to better use pack-style command language.

## Copyright note

The revision pack contains Pearson copyright wording. This app uses aligned command-word structure and terminology, but avoids copying the full worksheet questions verbatim into a public GitHub Pages app.
